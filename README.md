# Book-My-Trip-Boot-Strap
 A responsive travel booking website built with HTML5, Bootstrap 5, and CSS3. Features a hotel search engine, image carousels, deal tiles, and a fully adaptive layout across mobile, tablet, and desktop.  - 📱 Mobile → compact multi-column cards   - 💻 Tablet → medium-width layouts   - 🖥️ Desktop → full-width sections
